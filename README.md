# Python Module Examples

This repository contains example scripts demonstrating the usage of various Python modules.  
These scripts are designed for teaching and practice purposes, helping learners get hands-on experience with Python programming.

## Modules Used

- **Standard Python Modules** (no installation needed):  
  `random`, `time`, `os`, `turtle`, `re`

- **External Modules** (install using `pip` before running the scripts):  
  `pyautogui`, `pyfiglet`, `termcolor`, `numpy`, `matplotlib`, `pandas`, `requests`, `beautifulsoup4`

### Installing External Modules

Run the following command in your terminal or command prompt for each external module:

```bash
pip install module_name
